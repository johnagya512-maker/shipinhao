# 文案确认关卡：改写后停下，看清文案再决定是否花钱往下跑

## 用户诉求
"文案单独执行，确认文案符合预期后，再执行后面的步骤（配图/配音/合成）。
改写完文案需要一个可视化窗口给我确认。"
痛点：现在一条龙跑完，文案不满意时配图配音已经花了钱和时间，白忙活。

## 现状（已查证：能力其实都在，只是默认关 + 不聚焦）
- 暂停机制已存在：`pause_mode=key_nodes` 会在 **B 改写后**和 **E 生图后**暂停
  (orchestrator.py:54-82)，状态置 `awaiting_confirm`，记 `paused_at`。
- resume 从暂停点继续，已完成步骤走缓存不重算、不重复扣费 (orchestrator.py:405+)。
- 文案产物可编辑：ProductPreview 的 B 卡片可直接改字保存(不计费)、可「从此步重跑」让 AI 重写。
- 详情页有「确认并继续」按钮 (TaskDetailPage.tsx:215-226)。
- **问题1**：默认 `pause_mode='none'`，且开关埋在折叠的高级选项里 → 用户根本没触发暂停。
- **问题2**：暂停时文案混在右栏众多产物卡片里，左栏只有个小按钮，没有聚焦的"确认文案"体验。

## 方案：不重造轮子，做两件事——默认开 + 聚焦确认窗口

### 改动1：默认在文案后停（产品决策）
- 创建页 form 默认 `pause_mode` 从 `'none'` 改为 `'key_nodes'`(改写稿+生图后停，推荐项)。
- models.py / database 默认值也对齐(已存在 pause_mode 列，仅改默认；老任务不受影响)。
- 仍保留"不暂停/每步/自定义"供用户改。把"暂停确认"选择项的默认呈现说明强化。

### 改动2：详情页——文案确认聚焦窗口（核心体验）
当 `status==awaiting_confirm` 且 `paused_at==='B'`(或无改写时的文案步)时，
在右栏**顶部**插入一个醒目的「文案确认卡片」(ScriptReview)，取代/置顶现在那个小提示：

```
┌─ ✋ 文案已生成，请先确认 ───────────────────┐
│ [文案全文，可滚动，等宽舒适排版]               │
│                                              │
│ 确认后将开始配图+配音+合成，会产生费用。        │
│ [✅ 文案没问题，继续生成]  [✎ 改文案]  [🔄 让AI重写] │
└──────────────────────────────────────────┘
```
- **文案全文直接展示**(从 B 模块 output.script 取；无改写则 A 的 cleaned_text)。
- **✅ 继续生成** → 调 `api.resume(id)`(已有)，往下跑配图配音。
- **✎ 改文案** → 内联展开 textarea，保存调 `api.updateModuleOutput(id,'B',{script})`(已有，
  不计费)，保存后留在确认窗口，可再确认。
- **🔄 让AI重写** → 调 `api.rerunStep(id,'B')`(已有)，AI 重新改写，回到暂停态再审。
- 文案是"可视化窗口确认"的核心：醒目、全文、操作集中在一处，不用去右栏翻卡片。

### 实现细节
- 新增组件 `frontend/src/components/ScriptReview.tsx`(或直接内联进 TaskDetailPage)。
  倾向独立组件，TaskDetailPage 已 300 行。
- TaskDetailPage：算出 `awaitingScript = awaitingConfirm && paused_at==='B'`，
  为真时在右栏顶部渲染 ScriptReview，并把左栏那个通用"确认并继续"卡片在该情况下隐藏(避免两个继续按钮)。
- 文案文本来源：从 `modules` 里找 module==='B' 的 output.script；
  若该任务跳过改写(semi_auto/direct，但那些模式默认也不会停在 B)，兜底取 A 的 cleaned_text。
- 生图后停(paused_at==='E')维持现状(左栏确认按钮 + 右栏画廊)，本次不动。

### 不做（避免过度设计）
- 不做全屏 modal 弹窗——右栏顶部聚焦卡片已满足"可视化窗口"，且不打断查看其他产物。
- 不新增后端暂停点/字段——key_nodes 的 B 暂停点已满足。
- 不动生图确认体验。

## 验证
- 后端：默认值改动后 import 正常；创建任务默认 pause_mode=key_nodes。
- 前端 tsc。
- 端到端(用真实/模拟)：新建任务跑到 B 后状态=awaiting_confirm、paused_at=B；
  详情页出现文案确认窗口；点继续能往下跑；改文案保存生效；让AI重写回到暂停态。
- 打包同步桌面端。

## 待确认（plan 内默认决策）
- 默认暂停模式设为 key_nodes(改写+生图后停)。若你只想停在文案、生图不停，
  可改用 custom 只勾 B —— 但 key_nodes 更稳(图也能把关)，先按 key_nodes。
- 文案确认窗口放右栏顶部(非全屏弹窗)。
